# Visstick AI – Claude-plugins

Marktplaats met plugins voor Claude Code van Visstick AI.

## Installeren

```
/plugin marketplace add Dennis-star-create/visstick-plugins
/plugin install <plugin>@visstick
```

Updates ophalen: `/plugin marketplace update visstick`.

## Plugins

| Plugin | Wat het doet |
|---|---|
| [leadinfo-opvolging](plugins/leadinfo-opvolging/README.md) | Zet voor contacten van Leadinfo Autopilot een persoonlijke opvolgmail klaar als concept in Gmail of Outlook, met als doel een afspraak. Verstuurt nooit zelf. |
| [inbox-concepten](plugins/inbox-concepten/README.md) | Leest je nieuwe mail, sorteert hem op wat aandacht nodig heeft en zet conceptantwoorden in jouw toon klaar in Gmail of Outlook. Verstuurt nooit zelf. |
| [offerte-pitchdeck](plugins/offerte-pitchdeck/README.md) | Maakt van een klantgesprek in één keer een offerte (Word) en een pitchdeck van 8 slides (PowerPoint) in je eigen huisstijl, met prijzen uit je eigen prijslijst. Verstuurt nooit zelf. |
