# Visstick AI – Claude-plugins

Marktplaats met plugins voor Claude Code van Visstick AI.

## Installeren

```
/plugin marketplace add Dennis-star-create/visstick-plugins
/plugin install <plugin>@visstick
```

Updates ophalen: `/plugin marketplace update visstick`.

## Plugins

| Plugin | Wat het doet |
|---|---|
| [leadinfo-opvolging](plugins/leadinfo-opvolging/README.md) | Zet voor contacten van Leadinfo Autopilot een persoonlijke opvolgmail klaar als concept in Gmail of Outlook, met als doel een afspraak. Verstuurt nooit zelf. |
