# Instellingen Inbox-concepten

Kopieer dit bestand naar `~/inbox-concepten/instellingen.md` en vul het in.
De skill vraagt er ook zelf naar bij de eerste run in een gesprek.

## Jij
- naam: Voornaam Achternaam
- bedrijf: Bedrijfsnaam B.V.
- eigen e-mailadressen: naam@voorbeeld.nl, info@voorbeeld.nl
- wat je bedrijf doet (één zin): …
- aanspreekvorm: je            # je of u; de skill volgt verder de afzender
- taal: Nederlands             # antwoorden in de taal van de afzender

## Handtekening
```
Met vriendelijke groet,

Voornaam Achternaam
Bedrijfsnaam
```

## Voorbeeldmails (voor de toon)
Plak hier twee of drie antwoorden die je zelf schreef. De skill leest geen
andere verzonden mails om je toon te leren.
```
Hoi …,
…
```

## Vaste antwoorden
Feiten die de skill mag gebruiken. Staat iets hier niet, dan verzint hij het
niet maar zet hij [INVULLEN: …] in het concept.
- openingstijden / bereikbaarheid: …
- afspraaklink (optioneel): https://…
- tarieven of prijslijst (optioneel): …
- levertijd / reactietermijn: …

## Nooit een concept voor
Adressen of domeinen die je altijd zelf beantwoordt, of juist nooit.
- …@belangrijkeklant.nl
- nieuwsbrieven en automatische meldingen (standaard aan)

## Run
- periode: sinds de vorige run, eerste keer 24 uur
- maximaal aantal concepten per run: 15
